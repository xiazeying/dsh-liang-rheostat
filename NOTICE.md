# Demo assets

The MIT license in `LICENSE` covers the plugin source code in this repository.

The 16 demo wallpapers in `assets/wallpaper/` and the screen recording in
`docs/demo.mp4` are the author's demonstration assets, included so the plugin
can be tried immediately. They depict a real person and may carry portrait,
publicity, or other rights. If you redistribute the plugin or its demo assets,
make sure you have the necessary permissions, or replace the wallpapers and
video with assets you own. The source code remains MIT-licensed either way.

To use your own wallpapers, replace `assets/wallpaper/1.jpg` through
`16.jpg` with your own 16 images (same names) and refresh/reinstall the plugin.
